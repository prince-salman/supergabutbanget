# 🏆 MPL Indonesia 2026 - Head Coach Simulator

> **Simulator Karier Head Coach Mobile Legends: Bang Bang (MPL ID 2026)**
> Dibangun dengan **Next.js 14, TypeScript, Tailwind CSS, Web Audio API Synthesizer, & HTML5 Canvas Match Engine**.

---

## 🌟 Fitur Utama

### 1. 🛡️ 9 Tim Resmi MPL Indonesia 2026
- **Fnatic ONIC, RRQ Hoshi, EVOS Glory, Bigetron Alpha, Team Liquid ID, Alter Ego, Dewa United, Geek Fam ID, NAVI**.
- **100% Foto Resmi Pro Player & Coach** (76 potret foto pemain dan pelatih MPL ID).
- **100% Logo Resmi Tim** langsung dari aset MPL ID.

### 2. ⚔️ Sistem 10-Ban Draft Pick Tournament
- Mengikuti aturan turnamen resmi MLBB 2026 (Fase Ban 1, Pick 1, Ban 2, Pick 2).
- **Fase Tukar Hero (Hero Swap Phase)**: Pelatih bebas mengamankan role apa saja di awal/tengah/akhir dan menukar hero antar pemain.
- Stage Headset Intercom & dialog taktis bersama asisten pelatih dan pemain.
- Sinergi tim, counter-pick, dan kalkulasi draft composition score.

### 3. 🎮 2D Animated Land of Dawn Match Engine
- **Artwork Portrait Hero Resmi** pada setiap pion hero di map.
- **Gelombang Minion 3 Lane** (EXP, Mid, Gold).
- **Pertahanan Turret Laser** (Outer, Inner, Inhibitor, Base Crystal).
- **Kontes Turtle (Maksimal 3 Kali di 02:00, 04:00, 06:00)** dengan duel adu Retribution smite!
- **Marching Sanctuary Lord (08:00)** & **Enhanced Lord (12:00+)** yang menyerbu lane lawan.
- **Sistem Kill & Assist Dinamis**, First Blood, Double Kill, Triple Kill, Maniac, Savage, Shut Down, dan Wipeout.
- **Banner Animasi Kill Pop-up** dan audio announcer resmi MLBB.
- **Instruksi Taktikal Coach Live**: *Setup Lord, All-in War, Split Push, High Ground Defense, Invasi Buff*.

### 4. 📊 Format Best of 3 (BO3) & Regular Season
- Regular Season berjalan dalam format **Best of 3 (BO3)** (*First to 2 Wins*).
- Klasemen dinamis 9 tim dengan Game Difference & Poin.
- Statistik Lengkap Pemain & Hero Meta (Kills, Assists, KDA, MVP Points, Pick/Ban Rate).

### 5. 🔒 Babak Playoff & Malam Penghargaan (Awards Gala)
- Babak Playoff Double Elimination (Top 6 Regular Season).
- Malam Penghargaan: *Regular Season MVP, Finals MVP, First Team All-Star, Coach of the Season, Rookie of the Season*.

## 🚀 Menjalankan Project

```bash
# 1. Install dependencies
npm install

# 2. Jalankan development server
npm run dev

# 3. Build untuk production
npm run build
```

Buka browser di **`http://localhost:3000`**.
